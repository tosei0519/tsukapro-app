# つかプロ アプリ

白いブロックをつないだ写真を撮って、プログラムを読み、Bluetooth でロボットを動かす Web アプリです。

- `index.html` … アプリの画面（① とる → ② たしかめる → ③ うごかす）
- `recognize.js` … ブロックの読み取り。AI の学習はいらず、ブロックの本当の形（まえ・うしろ・みぎ・ひだり）を写真に重ねて、いちばん合う形を選ぶ
- `test/test.html` … 読み取りの試験。パソコンで描いた「写真もどき」を100枚読んで答え合わせする（今は 99/100）

## 開き方

カメラと Bluetooth は、**https のページ**か **localhost** でしか使えません（ファイルをダブルクリックで開くと使えません）。

- パソコンで試す：このフォルダでサーバーを立てて、Chrome で `http://localhost:8000` を開く
  ```
  python3 -m http.server 8000
  ```
- 教室のタブレットで使う：GitHub Pages などに、このフォルダをそのまま置く（https になる）

使えるブラウザ：Chrome / Edge（Windows・Mac・Chromebook・Android）。
**iPad・iPhone の Safari は Web Bluetooth に対応していないので、ロボットとはつながりません**（カメラの読み取りと画面の中の見本は動きます）。

## GitHub Pages に置く（別の端末で使う）

1. github.com でアカウントを作り、右上の「＋」→「New repository」。名前は `tsukapro-app`、**Public** にして「Create repository」
2. 「uploading an existing file」を押し、このフォルダの中身（`index.html`・`recognize.js`・`tsukapro-icon.svg`・`field-logo.svg`・`robot_top.png`・`README.md`）をまとめてドラッグして「Commit changes」
3. リポジトリの「Settings」→ 左の「Pages」→「Branch」を `main`・`/ (root)` にして「Save」
4. 1〜2分で `https://（アカウント名）.github.io/tsukapro-app/` が開けるようになる。この URL を Chromebook や Windows の Chrome で開く

直したあとは、同じリポジトリに新しいファイルをアップロードし直せば、数分で反映されます。

## Chromebook・Windows で使うとき

- ノートパソコンの内側のカメラは自分の方を向いているので、ブロックを撮りにくいです。**USB の Web カメラを下向きに付ける**か、タブレットになる Chromebook の**外側のカメラ**を使います（設定の「カメラ」で切りかえ）
- 「しゃしんを えらぶ」で、別に撮った写真を読ませることもできます
- 初めて開いたとき、カメラと Bluetooth の「許可」を求められるので「許可」を押します

## 使い方（こども向けの流れ）

1. 右上の「ロボットと つなぐ」を押して、`Uto_Robot_01` を選ぶ
2. ① くろい紙の上に、しろいブロックを**上から順に縦に**つないで置き、「とる」を押す
3. ② 読んだブロックが並ぶ。ちがうときは、そのブロックを押して選び直す（「？」が付いているのは自信がないブロック）
4. ③「うごかす」を押す。今動いているブロックがオレンジに光り、下の見本でもロボットが動く。「とめる」ですぐ止まる

ロボットとつないでいなくても、③ で画面の中のロボットだけ動かせます。

## つかプロフィールド（③ うごかそう）

③ の見本は、専用のフィールド（`tsukapro_13cm_print_ready.pdf`、130×65cm、1マス 13cm、横10×縦5マス）と同じ盤です。左半分はオレンジ、右半分は水色で、ロゴの位置も同じです。
- マスをタップすると、そこがスタートになります。同じマスをもう一度タップすると、ロボットの向きが右回りに変わります（この端末に保存）
- 並べたプログラムでフィールドの外に出るときは、見本に赤い × と「◯ばんめの ブロックで フィールドの そとに でちゃうよ」が出ます
- うごかしている途中で外に出るブロックが来たら、そのブロックを送る前にロボットを止めます
- 「まえ」1つで1マス（13cm）進むように、せんせい用の設定で「まえ・うしろ」の時間を合わせてください

## 電池の のこり

ロボットとつなぐと、上の帯に電池の のこり（%）が出ます。ロボットが止まっているときに 5 秒ごとに測った電圧から計算します。
- 20% より少なくなると赤くなり、「でんちが すくないよ」と出ます。
- 電池を入れず USB だけで動かしているときは「USB」と出ます。
- 充電池（ニッケル水素）を使うときは、設定の「電池」を切りかえます（アルカリと電圧がちがうため）。
- 電池の表示には、電池の電圧を送る新しいファームウェアが必要です。古いファームウェアのときは表示されません。

## 読み取りのコツ

- 背景は**黒や紺の紙**など、ブロックより暗い色にする（白い机の上だと読めません。そのときは設定で「ブロックが まわりより 暗い」をオンにして、黒いブロックを使う）
- ブロックは**つないだまま 1 本**にする（離れているブロックは読みません。いちばん大きいかたまりだけ読みます）
- カメラはなるべく真上から。かたむき ±24° まではそのまま読めます
- うまく読めないときは、設定（右上の歯車）の「読み取った 白黒の 図を 見る」で、ブロックが白く、まわりが黒くなっているか確かめる。ならないときは「明るさを 自動で 決める」を切って、しきい値を動かす

## せんせい用の設定（右上の歯車）

- 1つのブロックで動く時間（まえ・うしろ・みぎ・ひだり・あいだ）。アプリが命令ごとに `F1000` のように時間を付けて送るので、**ロボットのプログラムを書き直さなくても変わります**（ファームウェアは時間付きの命令に対応した版が必要）
- カメラの切りかえ、明るさ（しきい値）、音のオン・オフ

設定と最後のプログラムは、その端末のブラウザに保存されます。

## まだ確かめていないこと

- 本物のカメラで撮ったブロックの写真での読み取り（試験はパソコンで描いた写真だけ）
- 本物のロボットとの Bluetooth 接続と、命令の送信（ファームウェアの通信仕様に合わせて作ってある）
